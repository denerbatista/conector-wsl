WSL + Windows Workspace Connector

Política de Privacidade

Última atualização: 1º de outubro de 2026.

Documentação English

O WSL + Windows Workspace Connector (“conector”) é um software de código aberto, mantido por Dener Batista, que roda inteiramente na sua máquina. Ele conversa com o aplicativo do Claude pela entrada e saída padrão (stdio) do próprio computador e não tem servidor, conta nem banco de dados.

1. Dados coletados

Nenhum. O conector não coleta dados pessoais, não tem telemetria nem analytics e não envia dados de uso para nenhum lugar.

2. Como os dados são usados e guardados

  • O conector lê e escreve arquivos e executa comandos somente quando o Claude pede pelas ferramentas, e somente dentro das pastas que você libera (allowed_roots).
  • O resultado de cada ferramenta (saída de comandos, conteúdo de arquivos) volta para o aplicativo do Claude na mesma máquina. A partir daí, o tratamento segue a política de privacidade da Anthropic, não a deste conector.
  • O conector não grava cópias desses dados.

3. Compartilhamento com terceiros

Nenhum. O conector não faz requisições de rede. A única exceção é opcional e configurada por você: com a variável WSL_CONNECTOR_PREWARM, ele roda npx para baixar do registro do npm os pacotes que você listar. Nenhum dado seu vai junto nessa operação.

4. Retenção

O estado das sessões de terminal (pasta atual e variáveis exportadas) fica só na memória do processo e some quando a sessão fecha ou o conector encerra. Nada é guardado depois disso.

5. Seus controles

  • Você escolhe quais pastas o conector pode acessar.
  • O aplicativo do Claude pode pedir sua confirmação antes de cada ferramenta.
  • Você pode desinstalar o conector a qualquer momento; ele não deixa dados para trás.

6. Crianças

O conector não é direcionado a menores de 18 anos.

7. Mudanças

Mudanças nesta política são publicadas nesta página e no repositório do projeto, com a data atualizada.

8. Contato

Responsável: Dener Batista. Para dúvidas sobre privacidade, abra uma issue no GitHub.

English summary

The WSL + Windows Workspace Connector runs entirely on your computer and talks to the Claude app over local stdio. Data collection: none; no telemetry or analytics. Use and storage: it reads and writes files and runs commands only when Claude calls its tools, and only inside the folders you allow; results go back to the local Claude app and are not stored by the connector. Third-party sharing: none; it makes no network requests (the only exception is the optional WSL_CONNECTOR_PREWARM setting, which runs npx to fetch packages you list, without sending your data). Retention: session state lives only in process memory and is discarded when the session or the connector ends. Contact: Dener Batista, via GitHub issues.
